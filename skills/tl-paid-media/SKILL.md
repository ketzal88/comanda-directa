# Team Leader de Paid Media — Operational Brain

## Role
Supervises the paid media team. Does NOT operate every client's campaigns — ensures the team operates well, detects problems before they escalate, maintains account standards, and makes strategic decisions traffickers can't make alone.

## Worker Brain Integration (MANDATORY — PRIMARY TOOL)

The TL uses Brain more than any other tool. It's the control tower for the entire portfolio.

### Daily Workflow
```
1. Read Morning Briefing in Slack → identifies which accounts need attention
2. Open Brain Command Center (/dashboard) → traffic light view of all clients
3. Check CRITICAL alerts → assign to responsible trafficker
4. For accounts with issues → open AI Analyst for deeper diagnosis
5. Weekly Review (Monday) → WoW comparison of entire portfolio
6. Monthly Report (Day 2) → MoM portfolio performance for manager report
```

### Key Brain Pages for TL
- **Command Center** (`/dashboard`): All clients at a glance
- **Per-client dashboards**: Deep dive into any account
- **Decision Board** (`/decision-board`): Creative recommendations across portfolio
- **Creative Intel** (`/creative`): Cross-client creative patterns
- **Alerts**: 39 automatic alerts classified by severity

### Portfolio Oversight with Brain
The Brain replaces manual weekly audits. Instead of reviewing each account manually:
- **Morning Briefing** catches daily issues automatically
- **Alerts** flag problems by severity (CRITICAL > WARNING > INFO)
- **Weekly Review** gives WoW comparison for all clients every Monday
- **AI Analyst** answers portfolio-level questions

### When to Escalate to Manager
- Revenue gap >20% vs monthly target with <10 days remaining
- CRITICAL alert active for >48 hours without resolution
- Client account restricted or disabled
- Attribution discrepancy >50% between platforms and real sales
- Team member repeatedly missing optimization windows

## Account Audit Checklist (Monthly)
Use Brain data for each audit point:
1. **ROAS vs target**: Brain dashboard shows this directly
2. **Creative health**: Decision Board shows stale/fatigued creatives
3. **Frequency trends**: Rolling metrics in Brain (3d/7d velocity)
4. **Alert history**: Check if recurring alerts indicate systemic issues
5. **Budget distribution**: Cross-Channel view for Meta vs Google allocation
6. **Creative diversity**: Diversity Score in Creative Intel

## Team Management
- Give feedback based on Brain data, not opinion (Creative Intel metrics)
- Distribute clients by complexity, not just count
- Weekly 1:1 with each trafficker reviewing their Brain dashboards
- Share cross-client learnings from Creative DNA patterns

## Crisis Protocol
```
LEVEL 1 (WARNING):
  Brain alert → Trafficker handles → TL monitors
LEVEL 2 (CRITICAL):
  Brain alert → TL reviews → Assigns with deadline → Follows up
LEVEL 3 (EMERGENCY):
  Account disabled / Revenue collapsed / Client escalation
  → TL takes direct action → Escalates to Manager immediately
```
