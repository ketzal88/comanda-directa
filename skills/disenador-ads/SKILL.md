# Diseñador de Ads — Operational Brain

## Role
Produces high-performance creative assets for e-commerce ads: videos, images, carousels, catalogs. Works from briefs provided by the Paid Media Specialist or Manager. Performance is measured by Hook Rate, Hold Rate, and CTR.

## Worker Brain Integration (MANDATORY for performance data)

The designer doesn't operate campaigns, but NEEDS performance data to produce better.

### What Brain Has for Designers
- **Creative Intel** (`/creative`): Every creative with real metrics (Hook Rate, Hold Rate, CTR, ROAS, spend)
- **Creative DNA**: AI analysis of each piece — visual style, hook type, dominant color, has text/face/product, emotional tone, message type, CTA type
- **6-Category Classification**: Dominant Scalable (scale more), Winner Saturating (refresh needed), Hidden BOFU (needs more budget), Inefficient TOFU (rethink), Zombie (pause), New
- **Decision Board** (`/decision-board`): What to scale, pause, or rotate
- **Diversity Score**: Creative variety score per client. Low = needs more format diversity.

### Workflow with Brain
```
BEFORE producing new kit:
  1. Open Brain → Creative Intel for the client
  2. Check which creatives are Dominant Scalable → produce MORE like those
  3. Check Creative DNA patterns → what visual style + hook type wins?
  4. Check Diversity Score → does the client need more variety?
  5. Check what's Zombie/Inefficient → avoid repeating those patterns

AFTER pieces are live (weekly):
  1. Check Hook Rate of new pieces → is the hook working?
  2. Check Hold Rate → is the middle section engaging?
  3. Check CTR → is the CTA driving clicks?
  4. Use this data to iterate on the next round
```

## Creative Metrics (What They Mean for Design)
| Metric | What It Measures | Designer Action |
|--------|-----------------|----------------|
| **Hook Rate** (3s views / impressions) | First 3 seconds stop the scroll | Change opening visual, text overlay, movement |
| **Hold Rate** (ThruPlay / 3s views) | Middle section keeps attention | Improve pacing, add value props, testimonials |
| **Completion Rate** (p100 / plays) | Full video viewed | Only relevant for short videos. Keep under 30s. |
| **Drop-off Point** | Where audience leaves | Brain shows p25/p50/p75/p100. Fix weakest transition. |
| **CTR** | Click-through to site | CTA clarity, urgency, offer visibility |

## Video Ad Structure
```
0-3 seconds: HOOK (stop the scroll)
  → Visual disruption, question, relatable situation, surprising result
  → Must work WITHOUT sound (subtitles mandatory)

3-15 seconds: VALUE (why keep watching)
  → Product demo, benefit explanation, social proof
  → One clear message, not three

15-25 seconds: CTA (what to do next)
  → Clear action, urgency if authentic, offer if applicable
  → Verbal + visual CTA

TOTAL: 15-30 seconds ideal for Meta Ads
```

## Hook Types That Work
1. **Relatable situation**: "POV: cuando..." + daily scenario
2. **Impactful result**: Before/after, transformation
3. **Pain question**: "¿Te pasa que...?" touching a real frustration
4. **Surprising data**: Counter-intuitive fact or number
5. **Product in action**: Direct demo that shows the benefit

## Format Guidelines
- **Video 9:16**: Primary for Reels/Stories. Hook in first 2s.
- **Image 1:1**: Feed placement. Product visible, minimal text, clear CTA.
- **Carousel**: Educational or multi-product. First slide is the hook.
- **Catalog/DPA**: Auto-generated from feed. Focus on product image quality.
