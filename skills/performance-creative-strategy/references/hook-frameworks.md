# Hook Frameworks — Reference

## Hook Architecture (full structure)

Every performing ad follows this 6-part spine:

```
Hook → Pattern Interrupt → Story/Proof → Payoff → Offer → CTA
```

| Part | Purpose | Length (video) |
|---|---|---|
| Hook | Grab attention, create a loop | 0-3 sec |
| Pattern Interrupt | Disrupt expectations, force engagement | Embedded in hook |
| Story / Proof | Build credibility, maintain hold rate | 3-15 sec |
| Payoff | Deliver on the hook's promise | 15-20 sec |
| Offer | Specific, tangible ask | 20-25 sec |
| CTA | One clear action | 25-30 sec |

---

## Sistema de 3 Ganchos Simultáneos (Reels)

En el segundo 0, los 3 ganchos deben activarse al mismo tiempo:

### 1. Gancho Verbal (`<5 seg`)
Fórmula: **INTERRUPCIÓN + PROMESA + CURIOSIDAD**

Categorías y ejemplos:
| Categoría | Estructura | Ejemplo |
|---|---|---|
| **Negativos** | "No hagas X si querés Y" | "No compres suplementos sin leer esto primero" |
| **Curiosidad** | "Este truco cambia todo" | "Nadie habla de esto en el gym" |
| **Contraste** | "Antes X, ahora..." | "Antes gastaba $50K, ahora gano 3 veces más" |
| **Desafío** | "El 99% falla en esto" | "Solo 1 de cada 10 lo hace bien" |
| **Revelación** | "El secreto de X" | "Lo que los trainers no te dicen" |
| **Números** | "3 errores que..." | "5 cosas que destruyen tu metabolismo" |
| **Historia** | "Casi pierdo todo" | "En 2023 quebré mi negocio — acá lo que aprendí" |
| **Polémico** | "Los X mienten" | "La industria del fitness te miente" |

### 2. Gancho Visual (`1-2 seg`)
- Cambio brusco de ángulo
- Movimiento inesperado o rápido
- Objeto/elemento fuera de lugar
- Gesto exagerado o reacción
- Corte o transición abrupta
- Zoom dramático

### 3. Gancho Textual (en pantalla)
- Máximo 5 palabras
- Colores de alto contraste
- Tipografía bold, legible en mobile
- Sincronizado con lo verbal
- Ejemplos: "ERROR", "NO HAGAS ESTO", "SECRETO", "GRATIS HOY"

## Estructuras de Guión para Reels

### Estructuras CORE

**ERROR FATAL**
`Hook → Error común → Consecuencia → Solución → CTA`
*Mejor para: problema-solución, awareness 1-2*

**CONTRASTE / ANTES VS DESPUÉS**
`Hook → Situación inicial → Cambio clave → Resultado → CTA`
*Mejor para: transformación, awareness 2-3*

**REVELACIÓN**
`Hook → Misterio → Contexto → Revelación → CTA`
*Mejor para: curiosidad, awareness 1-3*

**LISTA / 3 PASOS**
`Hook → Tip 1 → Tip 2 → Tip 3 → CTA`
*Mejor para: educativo, awareness 2-4*

**MITO VS REALIDAD**
`Hook → Creencia popular → Desmentir → Nueva verdad → CTA`
*Mejor para: contrarian, awareness 2-3*

**HACK**
`Hook → Problema → Truco → Demostración → CTA`
*Mejor para: utilidad inmediata, awareness 2-3*

**HISTORIA CORTA**
`Hook → Situación → Conflicto → Lección → CTA`
*Mejor para: conexión emocional, awareness 1-2*

### Estructuras AVANZADAS

**PROBLEMA INVISIBLE**
`Hook → Problema que no sabés que tenés → Evidencia → Solución → CTA`
*Mejor para: audiencia inconsciente, awareness 1*

**ESCALERA DE AUTORIDAD**
`Hook (antes/después) → Punto inicial → Primer cambio → Estrategia clave → Resultado → CTA`
*Mejor para: posicionamiento experto, awareness 3-4*

**MOMENTO WTF**
`Hook impactante → Desarrollo → Giro inesperado → Conclusión → CTA`
*Mejor para: viralizabilidad, awareness 1-2*

**DESAFÍO CONTRACORRIENTE**
`Afirmación contraria → Explicación → Caso real → Nueva perspectiva → CTA`
*Mejor para: diferenciación de categoría, awareness 3*

**EFECTO BOOMERANG**
`Resultado impactante → Primer error → Segundo error → Revelación → CTA`
*Mejor para: storytelling complejo, awareness 2-3*

**LOOP DE RETENCIÓN**
`Hook → Pregunta abierta → Micro revelación → Nueva pregunta → Revelación final → CTA`
*Mejor para: maximizar hold rate / video completion, awareness 2-4*

## Benchmarks de Video Performance

| Métrica | Bajo | Aceptable | Excelente |
|---|---|---|---|
| Hook Rate (3s / impressions) | <20% | 20-35% | >35% |
| Hold Rate (ThruPlay / 3s views) | <25% | 25-40% | >40% |
| Video View Rate (P100) | <15% | 15-30% | >30% |
| P25→P50 drop | >40% | 25-40% | <25% |

**Diagnóstico de drop-off por timestamp:**
- Caída en P25 → intro débil, hook no sostiene
- Caída en P50 → contenido demasiado largo o pacing lento
- Caída en P75 → CTA llega muy tarde, guión se extiende
- Sin caída en P100 → guión perfecto, evaluar escalar

## Hook Testing Hierarchy

Orden de impacto (mayor a menor):
1. **Concepto / ángulo** (cambio de Reiss desire o awareness level)
2. **Hook** (verbal + visual + textual)
3. **Estilo visual** (UGC vs polished vs meme)
4. **Body copy**
5. **CTA**

Regla: antes de cambiar el hook, asegurate de que el concepto sea sólido. Un hook brillante sobre un concepto equivocado no escala.
