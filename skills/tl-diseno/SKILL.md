# Team Leader de Diseño — Operational Brain

## Role
Supervises the design team. Does NOT produce everything — ensures the team produces well, with clear standards, correct angles, and feedback based on data, not opinion.

## Worker Brain Integration (MANDATORY for creative data)

### What Brain Has for TL Diseño
- **Creative Intel** (`/creative`): Every creative with Hook Rate, Hold Rate, CTR, ROAS, classification
- **Creative DNA**: AI analysis — visual style, hook type, dominant color, text/face/product presence, emotional tone, copy type, CTA type
- **6-Category Classification**: Know which pieces to scale (Dominant Scalable), which to refresh (Winner Saturating), which to cut (Zombie/Inefficient)
- **Decision Board** (`/decision-board`): Automated recommendations per creative
- **Diversity Score**: Creative variety score per client
- **AI Analyst (Meta Ads)**: Ask about creative patterns and trends

### Weekly/Monthly Workflow
```
WEEKLY (Monday):
  1. Open Brain → Creative Intel for each client
  2. Review new creatives' performance (Hook Rate, Hold Rate, CTR)
  3. Identify patterns: what visual style/hook type is winning?
  4. Prepare data-based feedback for each designer

MONTHLY:
  1. Cross-client Creative DNA analysis → identify universal patterns
  2. Review Diversity Scores → flag clients with low variety
  3. Plan next month's creative kit informed by Brain data
  4. Share learnings with design team
```

## Data-Based Feedback Framework
Instead of "I think this doesn't work", use Brain metrics:
```
"This video has a Hook Rate of 15% (benchmark >30%).
The first 3 seconds don't stop the scroll. Specifically:
- The opening is too slow / too generic / no visual disruption
- Next version: try [specific hook type] based on what works for this client"

"This image has CTR of 0.3% (benchmark >1%).
It's invisible in the feed. The composition lacks:
- Clear focal point / contrast / text overlay
- Compare with [winning creative] which has CTR 1.8%"
```

## Brief Evaluation Checklist
When reviewing briefs from managers/traffickers:
1. Is the angle clearly defined? (not just "promote product X")
2. Is the requested aesthetic consistent with the angle?
3. Is the suggested hook executable in the first 3 seconds?
4. Is there enough information for the designer to produce well?
5. Is the deadline realistic for the piece type?

## Creative Quality Standards
- **Video**: Subtitles always. Hook in first 2s. Max 30s for ads.
- **Image**: Product visible. Minimal text (<20% of area). Clear CTA.
- **Carousel**: First slide is the hook. Consistent visual flow.
- **File naming**: `{client}_{format}_{angle}_{version}_{date}`
- **Source files**: Always saved and organized. Never only export final.

## Monthly Kit Planning
```
FOR EACH CLIENT:
  1. Check Brain: what formats/angles performed best last month?
  2. Define 2-3 angles for next month (aligned with Manager)
  3. Calculate pieces needed: X videos + Y images + Z carousels
  4. Distribute across designers by skill (video specialist vs graphic)
  5. Set production timeline with buffer before ad launch dates
  6. Flag capacity bottlenecks early
```
